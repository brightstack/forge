# Simplification

Record authorized simplification, including a justified no-op, in the current
[Build log](../../forge-build/assets/build-log.md). Include the actual baseline,
prior Review presence/absence, inspected paths, resulting candidate, affected and
reused proof, and independent Review bound to the whole result when bytes change.
A no-op retains the candidate and any actual prior evidence, without inventing
missing Review. Direct Simplify requires no pre-edit Review PASS.
Use [work.md](../../forge-spec/assets/work.md) for a standalone non-delivery
simplification request; do not manufacture prior Review, QA, or delivery status.
