# Design rubric

Load [Designer judgment](../../../../../agents/designer/instructions.md), accepted
visual revision/states, target UI standards, and
[design direction](../../../../forge-shared/references/design-direction.md) unless
the target selects a replacement.

## Check

Follow the affected user task in real rendered output. Compare hierarchy,
legibility, content relationships, type/color roles, alignment, responsive behavior,
clipping, overflow, and missing content against accepted or incumbent authority.
Exercise affected interaction, pending/empty/error/success states, keyboard/focus,
semantics, and accessibility. Challenge a consequential claim with a long existing
value, narrow viewport, keyboard recovery, or relevant state transition.

## Evidence and limits

Visual claims require actual rendering tied to the candidate; screenshots alone
do not prove interaction. Source can support a concrete accessibility trace.
State browser ownership and serialize shared mutation. Missing rendering is a gap
for required visual proof. Admit material fidelity drift or a demonstrated task,
usability, or accessibility failure. Do not demand a redesign, novelty, preferred
spacing, or pixel equality without accepted authority. An equally valid treatment
is not a defect.

## Common contract

Read [authority](../../../../forge-shared/references/authority.md),
[finding admission](../../../../forge-shared/references/severity.md),
[actual target harness sources](../../../../forge-shared/references/target-harness.md),
[returns](../../../../forge-shared/references/returns.md), and the assigned exact
candidate/base, authority packet, target harness, and allowed tools. Remain
read-only. Judge current obligations and present risks; no finding quota,
new requirements, or automatic repair authority. Severity follows actual impact;
remedy scope is assessed separately.

Use the dimension section in [review.md](../../../assets/review.md), unless a
selected leaf supplies its own report. Return selected rubric, inspected scope,
checks/evidence, actual results, findings with trigger/consequence/remedy boundary,
gaps, and PASS, REVISE, RETHINK, READY_FOR_USER, or BLOCKED with its basis. A
required unperformed check is incomplete. The Reviewer inspects the actual report
and relevant new log evidence before disposition.
